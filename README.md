# 🔍 Material Detective

An interactive **Class VI Science activity** that helps students learn how to group materials based on their properties.

## 📚 Project Details

* **Class:** VI
* **Subject:** Science
* **Topic:** Classification of Materials
* **Activity:** Group Materials Based on Their Properties

## ✨ Features

* 🔍 Explore different materials
* 💪 Identify Hard and Soft materials
* 💧 Learn Soluble and Insoluble materials
* 🔦 Learn Transparent and Opaque materials
* 🌊 Explore Floating and Sinking objects
* 🎮 Interactive classification games
* 🕵️ Mystery Material challenge
* 🧠 Final quiz with score

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. Start exploring the activities.

## 🎯 Learning Goal

Students understand that **materials can be grouped based on their properties** such as hardness, solubility, transparency, and floating/sinking.
